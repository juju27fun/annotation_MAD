# Revue locale indépendante

Répondre en français. Python via uv, uv.lock versionné ; JS via pnpm, versions dans
mise.toml. Pas de pip install, npm global ou brew install pour ce projet.

Ce dépôt est destiné à un partage GitHub privé. Ne jamais y introduire de références
humaines, de notes de confiance de l’auteur, de détections, d’identifiants historiques,
de chemins de sauvegarde ou de table de correspondance. Ne pas collecter les réponses
par une issue ou une PR visible par l’autre reviewer. Ne contacter personne sans
instruction explicite. Ne pas publier le dépôt ni créer des invitations implicitement.

Les deux relecteurs voient la même population et annotent indépendamment. Les
sources de données, le protocole de collecte et les consignes sont figés par release.
Une modification scientifique exige une nouvelle version et une décision sur les
annotations à refaire. Les réglages et performances restent hors de ce projet.
Les chiffres de population passent par paper/claims.toml. Ne pas charger ici le
registre privé du papier. L’auteur demande un démarrage direct sans choix de nom, des boutons de confiance visibles et un export simple. La session est identifiée localement et associée au relecteur à réception.

Les exports se sauvegardent localement puis s’envoient en JSON au coordinateur.
Préserver toutes les réponses existantes ; jamais de nettoyage du stockage navigateur.
Les tests en mémoire ne sont pas des tests visuels. Les instructions de l’auteur
restent prioritaires sur les instructions de ce fichier.
